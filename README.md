# EmpowerFin

A new Next.js workspace scaffolded with the app router, TypeScript, Tailwind CSS, and ESLint.

## Available commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`

## Tailwind

The project is configured for Tailwind CSS with `tailwind.config.ts` and `postcss.config.js`.
